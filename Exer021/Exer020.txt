What to implement:

1. common/generateId.ts

typescript
export function generateCustomId<T>(instance: T): string {
    const className = (instance as any).constructor.name.toLowerCase();
    const timeStamp = Date.now();
    const randomNum = Math.floor(Math.random() * 1000000000000);
    return `${className}-${timeStamp}-${randomNum}`;
}

2. Enum BookStatus

AVAILABLE, BORROWED, RESERVED, MAINTENANCE

3. Enum LoanStatus

ACTIVE, RETURNED, OVERDUE

4. Enum MemberRole

ADMIN, MEMBER

5. Class Review

Attributes: id (generateCustomId), memberId, rating (1-5), comment, createdAt
Methods: isPositive(), toString(), getters

6. Class Book

Attributes: id (generateCustomId), title, author, isbn, status, reviews (Review[])
Methods:
borrow() — validates AVAILABLE, changes to BORROWED
returnBook() — changes to AVAILABLE
reserve() — validates AVAILABLE, changes to RESERVED
addReview(memberId, rating, comment) — creates and adds Review
getAverageRating() — average of all ratings
isAvailable() — returns true if AVAILABLE
toString(), getters

7. Class Member

Attributes: id (generateCustomId), name, email, password, role, activeLoans (number)
Methods:
validatePassword(password) → boolean
isAdmin() → boolean
incrementLoans() — activeLoans++
decrementLoans() — activeLoans--
canBorrow() — returns true if activeLoans < 3
toString(), getters

8. Class Loan

Attributes: id (generateCustomId), book, member, loanDate, dueDate, returnDate, status
Methods:
returnLoan() — sets returnDate and status to RETURNED
markOverdue() — sets status to OVERDUE
isOverdue() — returns true if current date > dueDate and status is ACTIVE
getDaysRemaining() — returns days until dueDate
toString(), getters

9. Class BookRepository implements Repository<Book>

Methods: findById, findAll, save, delete
Extra: findByIsbn(isbn) → Promise<Book | null>
Extra: findByStatus(status) → Promise<Book[]>
Extra: findByAuthor(author) → Promise<Book[]>

10. Class MemberRepository implements Repository<Member>

Methods: findById, findAll, save, delete
Extra: findByEmail(email) → Promise<Member | null>

11. Class LoanRepository implements Repository<Loan>

Methods: findById, findAll, save, delete
Extra: findByMember(memberId) → Promise<Loan[]>
Extra: findByBook(bookId) → Promise<Loan[]>
Extra: findActive() → Promise<Loan[]>

12. Class AuthService

Receives MemberRepository via constructor
Methods:
register(name, email, password) → Promise<ApiResponse<Member>>
login(email, password) → Promise<ApiResponse<Member>>
getProfile(memberId) → Promise<ApiResponse<Member>>

13. Class BookService

Receives BookRepository via constructor
Methods:
addBook(title, author, isbn) → Promise<ApiResponse<Book>>
getAvailable() → Promise<ApiResponse<Book[]>>
addReview(bookId, memberId, rating, comment) → Promise<ApiResponse<Book>>
getTopRated() → Promise<ApiResponse<Book[]>> — average >= 4
searchByAuthor(author) → Promise<ApiResponse<Book[]>>

14. Class LoanService

Receives LoanRepository, BookRepository, MemberRepository via constructor
Methods:
createLoan(memberId, bookId, dueDate) → Promise<ApiResponse<Loan>>
returnLoan(loanId) → Promise<ApiResponse<Loan>>
getMemberLoans(memberId) → Promise<ApiResponse<Loan[]>>
getOverdueLoans() → Promise<ApiResponse<Loan[]>>
renewLoan(loanId, newDueDate) → Promise<ApiResponse<Loan>>
