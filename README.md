
# Estudos de Programação Orientada a Objetos (POO) com TypeScript

Este repositório destina-se ao estudo, prática e consolidação de conceitos fundamentais e avançados de Programação Orientada a Objetos (POO) utilizando a linguagem TypeScript.

## Sobre o Repositório

O objetivo principal deste projeto é servir como um guia de aprendizado contínuo, contendo exercícios, exemplos práticos e anotações sobre como aplicar os pilares da POO no ecossistema TypeScript.

## Conteúdos e Conceitos Abordados

* **Abstração:** Modelagem de entidades do mundo real em classes e interfaces.
* **Encapsulamento:** Controle de acesso a atributos e métodos utilizando visibilidades (public, private, protected e readonly).
* **Herança:** Reutilização e extensão de código através de classes base e derivadas (extends).
* **Polimorfismo:** Sobrescrita de métodos e comportamento dinâmico de objetos.
* **Interfaces e Type Aliases:** Contratos de código e tipagem estática aplicados à POO.
* **Classes Abstratas:** Definição de estruturas base e métodos abstratos a serem implementados por subclasses.
* **Getters e Setters:** Manipulação controlada de propriedades privadas.
* **Princípios SOLID:** Aplicação das boas práticas de arquitetura e design de software orientados a objetos.

## Estrutura do Repositório

* `/src`: Contém os códigos de exemplo e exercícios organizados por módulo ou tema de estudo.
* `/docs`: Anotações teóricas e resumos sobre os conceitos de POO e TypeScript.

## Pré-requisitos

Para executar os exemplos deste repositório, você precisará ter instalado em sua máquina:

* Node.js (versão 16 ou superior)
* npm ou yarn
* Git

## Instalação e Execução

1. Clone o repositório:
   git clone [https://github.com/andrey-seg/POO.git](https://www.google.com/search?q=https://github.com/andrey-seg/POO.git)
2. Acesse o diretório do projeto:
   cd POO
3. Instale as dependências:
   npm install
4. Execute os arquivos TypeScript (usando ts-node ou npx tsx):
   npx tsx src/caminho-do-arquivo.ts

## Tecnologias Utilizadas

* TypeScript
* Node.js
* TS-Node / TSX (para execução direta de arquivos TypeScript)
